# Marcel · AI Command Center

Personal command-center snapshot for Marcel Krämer-Riedesel.

## Open from anywhere

**https://marcelkraemerriedesel-pixel.github.io/ai-command-center/**

Hosted on Marcel's GitHub account:
`marcelkraemerriedesel-pixel/ai-command-center`

## What it is

A single-file HTML dashboard that stitches together live data pulled by the
Cursor Cloud Agent from connected tools:

- Google Calendar
- Gmail
- Jira SLF
- Confluence
- Granola
- Cursor agent link

## Refresh

Ask the Cursor agent: **Command Center refresh**. It re-queries the MCP tools,
updates `tries/marcel-ai-command-center/index.html`, and redeploys to GitHub Pages.

## Privacy

The public URL is world-readable. Do not paste secrets from emails into the dashboard.
